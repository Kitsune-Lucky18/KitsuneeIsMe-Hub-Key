Getting Started
Setup Guide
1

Fork / Create GitHub Repo

Create a new GitHub repository named hub-auth under your account KitsuneeIsMe. Make it public.

2

Upload keys.json

Put the keys.json file in the root of your repo. The script fetches it from:
https://raw.githubusercontent.com/KitsuneeIsMe/hub-auth/main/keys.json

3

Deploy this website (GitHub Pages)

Put this index.html in a repo named KitsuneeIsMe.github.io and enable GitHub Pages. Your site will be live at kitsuneeisme.github.io.

4

Add / Remove Keys

Use the Admin Panel above to generate keys. Copy the JSON output and commit it to keys.json. Changes go live within ~1 minute (GitHub CDN cache).

5

Distribute to Users

Share keys via Discord DMs. Users enter the key in the hub's key screen. Keys auto-expire based on their type — no manual cleanup needed.
